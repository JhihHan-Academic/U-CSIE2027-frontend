# Evolved Snake

### Vercel Link

[Snack Game](https://snack-game-virid.vercel.app/)

### Design Concept

本遊戲設計的核心在於保留傳統 Snake 的經典體驗，同時加入多種道具與連鎖機制，讓玩家在遊戲節奏上有更多策略選擇。穿牆機制保持了流暢性，減少邊界碰撞的挫折，而速度與無敵道具則能讓玩家在短時間內感受強化快感。毒物與食物壽命的設定增加了動態挑戰，讓玩家不能單純等待安全區域，而必須快速判斷與移動。整體風格以簡潔直覺為主，讓玩家可以專注於操作與連續得分的樂趣。

### How My Version Is Different

我的版本與原版 Snake 的最大差異在於加入了多重食物類型與可變道具效果。除了基本紅色食物外，還有黃金食物、毒物與限時道具，每種元素都會影響分數與蛇身長度，讓遊戲不再只是單一吃食物成長。搭配連鎖計分、食物壽命與無敵模式，玩家要同時管理得分與生存，遊戲策略性顯著提升。

### How To Play

- 使用方向鍵或 W/A/S/D 控制蛇的移動方向。
- 按 `Space` 開始或重新開始遊戲。
- 按 `P` 暫停或繼續遊戲。
- 吃到紅色食物可 +1 分，黃色食物可 +3 分，紫色毒物會扣分並縮短蛇身。
- 食物會在有限時間內消失，未被吃掉會重新生成新食物。
- 道具可讓你暫時加速、減速或進入無敵狀態。
- 當蛇撞到自己時，遊戲結束；若處於無敵狀態則可免疫自撞。


## 遊戲規則

核心設定
- 棋盤: 20 × 20 格
- 控制: 方向鍵 或 W/A/S/D 控制方向（不可直接反向）
- 開始/重玩: `Space`，暫停/繼續: `P`
- 畫面行為: 穿牆（從一邊出界會從對邊出現）

食物種類
- 普通 (紅色): 吃到 +1 分
- 黃金 (金色): 吃到 +3 分（出現機率較低）
- 毒物 (紫色): 吃到 -1 分，且會縮短蛇身（若分數為 0 則維持 0）

道具 (Power-ups)
- 加速 (`speed`): 在有限時間內遊戲速度提升
- 減速 (`slow`): 在有限時間內遊戲速度降低
- 無敵 (`invincible`): 在有限時間內觸碰自己不會死亡

連鎖機制（Combo）
- 在 `comboTimeout`（預設 2 秒）內連續吃到食物會增加連鎖倍率，倍率會疊加並影響此次得分。若超過時限未吃到新食物，連鎖歸零。

食物壽命
- 每個食物有壽命（預設 5 秒），若在壽命內未被吃掉會自動消失並重新產生一個新食物。

其他
- 分數無上限，遊戲以「撞到自己（非無敵時）」結束。遊戲結束後畫面會停止，按 `Space` 可重置並開始新局。
- 畫面右側有說明面板顯示食物與道具說明。

實作說明（開發者快速提示）
- 主要程式檔: `src/components/SnakeGame.vue`
- 啟動 (本機): `npm install` → `npm run dev`

待調整其他規則加入或調整參數（例如食物壽命、連鎖時限、道具種類）。
